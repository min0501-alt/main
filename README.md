# 모니모여 · 스마트 회의실

제공된 HTML을 기반으로 한 회의실 관리 웹 앱입니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd main
npm run dev
```

기본 포트는 3000이며 `PORT` 환경변수로 변경할 수 있습니다.

## 기능과 저장

회의실 예약, 내 일정, 회의록, 비품 및 고장 신고, 분실물, 이용 리포트를 제공합니다.
시연 데이터와 변경 사항은 현재 브라우저의 localStorage에 저장됩니다. 서버 DB나 사용자 간 공유는 연결되어 있지 않습니다.

일반 브라우저에서는 AI 대신 원본의 규칙 기반 기능이 동작합니다. Claude 호스트 연동 기능, 별도 음성 인식 서비스, 실제 알림 발송은 외부 서비스 연결이 필요합니다.
녹음은 마이크 권한 및 브라우저의 보안 컨텍스트 지원이 필요합니다.
